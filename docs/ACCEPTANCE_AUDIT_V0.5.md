# CreatorOS v0.5 首版验收审计

审计日期：2026-09-09

结论：**未通过整体验收**。当前具备可继续开发的完整骨架，并已真实跑通 Bilibili 链接下载与关键帧视觉拆解，但“真实视频逆向 -> 原创脚本 -> 角色一致的 AI 视频 -> 配音字幕合成”尚未端到端闭环。

## 八项主线结果

| 项目 | 结果 | 当前证据与缺口 |
|---|---|---|
| 1. 平台视频链接下载与上传兜底 | 部分通过 | Bilibili 链接已有真实成功记录；本地 MP4 上传已通过。小红书、抖音尚无稳定端到端验收记录，失败时会提示上传。 |
| 2. 真实视频关键帧、字幕和镜头逆向 | 部分通过 | 已真实提取关键帧并由 Qwen 生成结构化视觉拆解；当前最多均匀抽取 5 帧，未自动提取语音/字幕，也未真实分析声音、完整转场和精确节奏。 |
| 3. 结构化等效 Prompt | 部分通过 | 已有总 Prompt、逐镜头视觉 Prompt、negative hints 和原创边界；前端未独立展示负面 Prompt，可复用/禁止复制字段仍可进一步结构化。 |
| 4. 结合账号角色生成原创脚本 | 功能通过，端到端未验收 | 正式模式已接 Qwen，并使用账号定位、角色和拆解结果；支持编辑、保存、重新生成及历史草稿。当前留存草稿均为 Demo，没有从真实拆解生成正式脚本的完整验收产物。 |
| 5. 角色参考图生成与留存 | 部分通过 | DashScope `qwen-image-2.0` 生图实现及上传留存已存在，运行能力显示可用；当前运行目录没有可复核的真实生成角色图。更重要的是角色图没有传入通义万相生成链路。 |
| 6. 真实 AI 视频生成 | 未通过 | 通义万相和小云雀客户端存在，但运行状态为 `configured_not_verified`，默认策略为 `compose`。没有外部模型成功生成并留存的视频；通义实现当前还是文生视频，角色参考图参数未使用。 |
| 7. 配音、字幕和镜头合成 | 组件通过 | 本地 FFmpeg 路径可输出 9:16 MP4，使用 macOS 中文 TTS，字幕文字烧录在画面中，测试验证含 AAC 音轨。但它合成的是静态角色卡片，不是多个真实 AI 视频镜头。 |
| 8. 留存与导出 | 基本通过 | SQLite 保存分析、草稿、任务和导出；localStorage 恢复当前任务；服务重启会把运行中任务标记失败。ZIP 可导出文案、标签、脚本、Prompt、逆向结果和已有成片。缺少独立的任务重试 API/状态恢复。 |

## 首版七条验收结果

1. 成功读取或提示上传：**部分通过**，Bilibili 和上传已证实，其余平台未稳定验证。
2. 显示真实视频拆解：**部分通过**，真实关键帧视觉拆解已成功，但不是完整多模态拆解。
3. 逐镜头 Prompt 和原创脚本：**部分通过**，两段能力分别存在，尚无同一真实任务闭环证据。
4. 指定角色生成新视频：**未通过**，外部视频模型未成功，且角色图未传入该模型。
5. 页面显示任务进度：**通过**。
6. 播放并下载有画面、配音、字幕的竖屏 MP4：**仅本地合成通过**，不满足“真实 AI 视频生成”前提。
7. 刷新后结果仍存在：**基本通过**，完成结果与任务 ID 可恢复；服务重启会中断正在执行的线程任务并标记失败。

## 最高优先级修复顺序

1. 将 `VIDEO_RENDER_STRATEGY` 切到外部 provider，并完成一次真实模型成功请求与产物下载。
2. 给视频模型真正传入甜甜、铁柱角色参考图；当前通义路径的 `reference_video_url` 明确未使用。
3. 将真实拆解、正式脚本、视频 Prompt、外部 AI 镜头、最终合成绑定为同一 draft/job 链路。
4. 增加 ASR/OCR 和音频分析，至少输出字幕时间轴、说话内容、声音类型、镜头边界与节奏。
5. 用 Bilibili、一个小红书或上传视频分别跑完整 E2E，并把角色图、分析 JSON、正式脚本、模型 task ID、AI 原片、最终 MP4 和 ZIP 保存为验收夹具。
6. 补充真实模式自动化测试；现有 `3 passed` 主要验证 Demo 和 mock，不等于生产链路验收。
