# 单机内测部署

范围：单账号，真实拆解/原创剧本/角色图/HappyHorse短片/导出。趋势和复盘允许使用固定数据。首版成片3–15秒；旧长剧本需重新生成或手工精简。字幕由模型生成，发布前需人工检查。

## 启动

服务器需要 Docker Compose。在项目根目录执行：

```sh
docker compose up -d --build
```

后端凭据使用服务器上的 `backend/.env`，不会打包进镜像。至少配置 `QWEN_API_KEY`、`QWEN_BASE_URL`，参考现有 `.env.example`。默认服务只绑定服务器本机8080端口，可通过 SSH 转发访问：

```sh
ssh -L 8080:127.0.0.1:8080 USER@SERVER
```

然后访问 http://127.0.0.1:8080 。前后端由同一个服务提供，无需Vite开发服务器。

## 分享给内测用户

公网入口使用带HTTPS和访问认证的反向代理。当前账号页面不是服务端身份认证，不应直接开放未认证的公网入口。配置 `CREATOROS_ALLOWED_HOSTS=你的域名` 和 `CREATOROS_ALLOWED_ORIGINS=https://你的域名` 后重启。外部域名、服务器及代理还未配置。

## 结果留存

`backend/runtime` 挂载为持久化目录，包含SQLite、上传、生成结果及导出包。每个视频目录的 `provider-task.json` 保存上游任务号与请求指纹；服务重启后页面任务显示中断，点击重新生成会查询同一个上游任务。不要删除该目录，不要启动多个后端worker。

## 验收边界

HappyHorse已独立实测15秒、1080x1920、24fps、双角色、多镜头、字幕和音轨。正式流程已接入同样的角色映射和参数，但发布前仍需实际检查生成内容。平台链接受限时使用上传。无自动发布、无支付、无多租户、无长视频拼接。

本机未验证Docker镜像构建时，不应把部署文件存在视为服务器部署成功。
